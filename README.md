# North Asia Solar Intelligence

个人北亚光伏市场情报工作台，覆盖日本、韩国、台湾。在线地址：**https://needxu.github.io/NorthAsiaSolar/**。无需在用户电脑安装或启动服务。

## 当前能力

- React + TypeScript + Vite，默认中文，深浅主题、手机布局，三个市场独立切换。
- 本地语言原文优先：日语、韩语、繁体中文；英文国际报道作补充。实际来源见 `scripts/sources.json`，当前配置 16 个来源。
- 区分政府原始来源、企业官方自述、媒体报道；保留原始标题、语言、发布日期、原文地址、地域归属依据与证据片段。
- 按主题、日期、优先级、来源类型、事件类型、政策方向线索组合筛选。同行支持中英日韩常见品牌别名检索。
- 政策与企业动态分开：政府政策公告、政策会议、竞标采购、MOU、购电协议、项目计划/建设、竣工投运、合作供货、产品发布。
- 最近七天中文情报简报（按北京时间确定日期范围，按来源当地发布日期纳入），附原题、原始链接、事件与证据，可导出 Markdown 或打印/PDF。
- 模拟驾驶舱独立保留，通过明确的演示入口进入，不混入真实新闻。装机、价格、预测未接入可靠来源时不显示模拟值。

## 政府政策与精度边界

政府来源包括东京都、日本环境省、韩国政府政策简报（光伏关键词检索）、台湾经济部及能源署新闻/业务公告。业务公告 RSS 从政府官方 RSS 目录查得并实际验证，不把多年未更新的旧栏目当作当前政策。

政策“支持线索 / 限制线索 / 混合线索 / 未判定”是保守的原文证据提示，**不等于已核实的政府总体态度、法律效力或业务结论**。媒体报道和未读取正文的条目不生成官方政策方向；草案、会议与已生效法规不能混为一谈，系统不自动补出未核实的生效日期。适用地区、补贴对象、金额、币种、申请期和效力仍须按链接原文核对。

精度保护包括：

- 不把未发现公告解释为政府不支持光伏。
- 拒绝“只顺带提到太阳能”的综合投资/半导体新闻进入核心列表。
- 事件优先根据标题，再读取光伏相关句子，避免把无关段落中的 MOU、建设或发布词套到该条事件。
- MOU 不等于正式供货订单，预计投运不等于已完成。评级“发布”不等于新品发布。
- 日文/韩文法规、安全检查与竞标原文须保留出处；企业发布的信息标为企业自述，不作为第三方独立验证。

**覆盖缺口**：日本经济产业省及资源能源厅在实际验证时返回 HTTP 403，未绕过限制；环境省与东京都来源不代表已完整覆盖日本全国政策。所有地方补助、所有厂商与所有历史政策也未完整纳入。网页显示覆盖说明与来源状态。

## 中文整理方式与费用

只处理公开新闻文本，不发送用户私密数据，也不购买或调用付费 API。

1. 繁体中文用 OpenCC 转简体，保留原文。
2. 日语、韩语、英文优先使用已验证的无密钥公开网页机译响应。它不是正式商业 API，可能限流或失效；收到 403/429 后不绕过限制或反复重试。
3. 失败时用 GitHub 标准运行器本地 M2M100-418M 补充，加载前验证 MIT 许可、记录固定模型修订；禁用远端自定义代码。权重缓存在 Actions 中。
4. 译文做数字一致性检查；兼容全角数字、日期写法、常见序数和星级的等价形式，不接受 28.29% 变成 28.30% 等实质变化。未通过检查时保留原文并显示待处理。

全部为机器翻译/节译，**不是人工政策审核或已验证业务分析**；原文单位、条件与语境仍须核实。晶科影响栏明确保留待核实提示，不生成没有依据的销售结论。

## 自动更新与数据保留

GitHub Actions 每天计划在 **北京时间 08:00（UTC 00:00）**采集；调度可能延迟或停用，不保证准点。网页每五分钟检查已发布的数据文件，重新打开也会检查；页面刷新不会直接启动抓取。

源读取失败保留旧归档，展示各源状态、最近尝试及最近完整成功时间。翻译失败独立展示，不能视为已全部整理。采集只接收有效发布日期、近期 90 天和 HTTPS 原文地址，按国家+规范URL及同市场原题去重；当前最多保留 3000 条，并非永久数据库。

纯界面更新会复用新鲜归档，避免重复抓取和翻译；日更/手动采集不跳过。采集逻辑或来源配置更改会重跑。状态推送支持有限重试、同步和非强制 rebase，不覆盖其他提交。

## 关闭 / 重新开放

网页右上角「公开访问开关」指向：

https://github.com/NeedXu/NorthAsiaSolar/actions/workflows/public-access.yml

需要 GitHub 仓库操作权限，运行默认 **close** 撤下应用和新闻数据，选择 **open** 恢复。关闭不是删除域名：网址只显示“访问已关闭”页面，不含应用脚本或新闻数据。日更仍可归档到 GitHub，但不会重发应用。部署与验证需要等待，不能保证瞬时关闭。

已实际验证：关闭页生效、新闻 JSON 和上一版 JS/CSS 不可访问；关闭状态下日更未重发应用；重新开放后首页及数据可访问。结果保存在 `.deploy/site-status.json`。

GitHub 自动令牌的删除 Pages 站点请求曾返回 403，故不依赖该管理权限。关闭不隐藏公开仓库，也无法召回缓存或已下载内容；如需真正私有情报，后续须增加登录和私有存储。

## 开发与验证

Node.js 22+（当前验证版本 24）、Python 3.12+。

```bash
npm ci
npm run dev
npm run build
npm test
python3 -m pip install -r requirements-collector.txt
python3 -m unittest discover -s tests -v
python3 scripts/collect.py
```

本地 localhost 地址只能在运行服务的同一机器访问；云端 localhost 不是用户电脑的网址。正常使用请访问上方在线网址。

翻译脚本另需 CPU PyTorch 和 `requirements-translation.txt`；安装方式以工作流为准。支持 `FEED_OUTPUT=/tmp/probe.json` 临时输出。验证覆盖本地时区、原文链接、政策否定、草案、MOU/完成阶段、综合新闻误收、翻译数值保护、关闭与推送恢复。浏览器检查覆盖中文、筛选、原文证据、出处、周报与移动端。

## 目录

```text
src/App.tsx                      真实数据 UI、轮询、来源/事件筛选、详情、周报
src/DemoApp.tsx                  独立模拟演示
src/services/                   数据校验、筛选、品牌别名、北京时间周报
scripts/sources.json             原文来源、语言、类型、时区与列表适配
scripts/collect.py               RSS/HTML 原文采集、日期验证、事件线索与归档
scripts/translate.py             中文处理、数字校验及免费翻译降级
scripts/verify-site.py           实际上线/关闭 HTTP 检查
scripts/build-closed.py          不含应用和数据的关闭页
scripts/push-main.sh             非强制推送恢复
public/data/feed.json            新闻归档、覆盖缺口与来源/翻译状态
.github/workflows/               日更、发布、访问开关与独立来源验证
```

下一阶段可逐步增加已核实的地方政策原文/法规基线、官方证据交叉核对、项目容量和合作方的人工校核字段，再引入私有数据库与历史周报。政策结论与业务建议须始终能回溯原文证据。

日期精度：原文发布日期保留来源当地日历日期，不把日本/韩国的零点公告错误显示成前一天。HTML 仅有日期时标记 `datePrecision: day`，不对外声称已取得准确发布时间。企业页面若只给通用公司名或脚本外壳，则用官方列表原题/日期和摘要，不冒充取得正文。
